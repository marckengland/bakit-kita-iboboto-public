# Proposed data reuse terms

BetterGov's pinned Open Congress dataset declares CC0 1.0. Its unchanged license is included as [UPSTREAM_CC0.txt](UPSTREAM_CC0.txt).

CC0 1.0 is proposed for this batch's structured factual records and original summaries, subject to maintainer approval. The candidate is not yet approved for import or publication. The application's code license is separate.

This batch links to source documents. It does not redistribute full documents, photographs, artwork, or their rights. A source URL or a government domain is not a license for every item it hosts.

Keep the source links, observation dates, unknown fields, and correction history when adapting these records. Those details let readers check what the data actually establishes.
